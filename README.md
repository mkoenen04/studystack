# StudyStack

StudyStack is a web application that helps college students track assignments and deadlines and automatically generates a realistic weekly study schedule. Students enter their courses, assignments, and recurring commitments (work hours, extracurriculars), and StudyStack fits study blocks into their real free time, spreading the workload when several deadlines fall close together.

## Planned Features
- User registration and login
- Course and assignment management (due date, priority, estimated hours, status)
- Availability settings for work hours and extracurricular activities
- Automatic weekly schedule generation
- Dashboard of upcoming deadlines and progress

## Technology Stack
- **Frontend**: React
- **Backend**: Python, FastAPI
- **Database**: PostgreSQL
- **Containerization**: Docker, docker-compose
- **CI/CD**: GitHub Actions
- **Deployment**: Google Cloud Run
- **Project Management**: Jira (sprints, user stories) and Confluence (project documentation)
- **AI Development Tools**: GitHub Copilot
